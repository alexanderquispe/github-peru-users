# GitHub Peru Users Extraction

This project extracts unique GitHub users from Peru using the GitHub REST API and explores available user-level data fields.

## Setup

1.  **Clone the repository**:
    ```bash
    git clone <repository-url>
    cd github-peru-users
    ```

2.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Environment Variables**:
    Create a `.env` file and add your GitHub Personal Access Token:
    ```env
    GITHUB_TOKEN=your_token_here
    ```

## Usage

Run the extraction script:
```bash
python extract_users.py
```
